# JointWise Prototype Application

Early prototype for the JointWise medical imaging platform.

## Status

This is an early prototype and predecessor to the current production implementation: **[JointWise-Final-App](https://github.com/marccodesstuff/JointWise-Final-App)**.

## Purpose

Initial exploration of MRI visualization and model inference integration before final architecture decisions were made. Preserved here for historical reference and to document the evolution of the JointWise system.

## Project Context

"JointWise" is an undergraduate thesis project at Angeles University Foundation (Jan 2025 – Mar 2026) focused on ACL and meniscus tear detection from MRI scans using YOLOv11 stacking ensemble, achieving **75.17% mAP**, **88% FROC**, and **73.50 F1-score**.
